# claude-code-sandbox
A sandbox repository for experimenting with Claude Code

## Available Slash Commands

### `/test`
テストを実行して結果を分析します。

**使用方法:**
```
/test [引数]
```

**実行内容:**
- テストスイートの実行 (`npm test`)
- テスト結果の分析
- 失敗したテストの原因調査
- テストカバレッジの確認
- 改善が必要な箇所の特定と報告

### `/review`
コードレビューを実行します。

**使用方法:**
```
/review <ファイルまたはディレクトリ>
```

**レビュー観点:**
- コードの可読性と保守性
- ベストプラクティスへの準拠
- 潜在的なバグやエラー処理
- パフォーマンスの問題
- セキュリティ上の懸念

### `/create-pr`
カレントブランチからPull Requestを作成します。

**使用方法:**
```
/create-pr [--title "PRタイトル"]
```

**引数:**
- `--title`: PRのタイトルを指定（省略時は変更内容から自動生成）

**実行内容:**
1. カレントブランチと変更状態を確認
2. コミット履歴と変更差分を分析
3. PRテンプレート (`.claude/pr-template.md`) を使用して本文を生成
4. GitHub上にPRを作成（ベースブランチ: `prod`）

### `/merge-pr`
カレントブランチに関連するPRをマージします。

**使用方法:**
```
/merge-pr [--merge|--squash|--rebase]
```

**引数:**
- `--merge`: 通常のマージコミット（デフォルト）
- `--squash`: Squashマージ
- `--rebase`: Rebaseマージ

**実行内容:**
1. カレントブランチのPR情報を取得
2. PR状態とマージ可否を確認
3. 指定されたマージ方法でマージを実行
4. マージ後、ブランチを削除

### `/explain`
コードの動作を詳しく説明します。

**使用方法:**
```
/explain <ファイルまたはコード>
```

**説明内容:**
- コードの目的と機能
- 主要なロジックの流れ
- 使用されている重要な概念やパターン
- 依存関係
- 使用例
